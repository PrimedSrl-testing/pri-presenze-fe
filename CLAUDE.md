# pri-presenze-fe

## Dev server

Il progetto gira **sempre in dev mode** (Next.js con hot reload attivo). Le modifiche al codice vengono ricaricate automaticamente.

**Non riavviare `node.exe` e non lanciare il dev server.** In particolare NON eseguire:

- `npm run dev`
- `npm start`
- `yarn dev` / `pnpm dev`
- `kill node.exe` / `taskkill /IM node.exe`
- comandi equivalenti che killano o avviano il processo Node

Dopo aver modificato componenti, pagine, API routes, ecc. assumere che le modifiche siano già live senza alcuna azione aggiuntiva.
